Python langugaes supports several types of operators. In this section, we will focus on few of them.

#### Assignment Operators 
Assignment operators are used to assign values tot variables. Let us take = as an example. Equal sign in mathematics shows that two vlaues are equal, however in Python it means we are storing value in a cretain variable and we call it assignment or a assigning value to a variable. The table below shows the diffrent types of python assignent operators, taken from w3school.

#### Arithmetic Operators:
Addition(+): a + b
Subtraction(-): a - b
Multiplication(*): a * b
Division(/): a / b
Modulus(%): a % b
Floor division(//): a // b
Exponentiation(**): a ** b

Example: Integers 
```Python
-- Arithmetic Operations in Python 
-- Integers

print('Addition: ', 1 + 2)        -- 3
print('Subtraction: ', 2 - 1)     -- 1
print('Multiplication: ', 2 * 3)  -- 6
print ('Division: ', 4 / 2)       -- 2.0  Division in Python gives floating number
print('Division: ', 6 / 2)        -- 3.0         
print('Division: ', 7 / 2)        -- 3.5
print('Division without the remainder: ', 7 // 2)   -- 3,  gives without the floating number or without the remaining
print ('Division without the remainder: ',7 // 3)   -- 2
print('Modulus: ', 3 % 2)         -- 1, Gives the remainder
print('Exponentiation: ', 2 ** 3) -- 8 it means 2 * 2 * 2

Example: Floats
```Python 
-- Floating numbers 
print('Floating Point Number, PI', 3.14)

```

Example: Complex numbers 
```Python
-- Complex numbers 
print('Complex number: ', 1 + 1j)
